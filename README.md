# Titanic Survival Prediction Using Logistic Regression

## Project Description

This project uses Logistic Regression to predict whether a passenger survived the Titanic disaster.

## Dataset

The Titanic dataset from Kaggle is used for this project.

The dataset contains information about passengers such as:
- Passenger Class
- Age
- Number of Siblings or Spouses
- Number of Parents or Children
- Survival Status

## Features Used

- Pclass
- Age
- SibSp
- Parch

## Target Variable

Survived

- 0 = Did not survive
- 1 = Survived

## Algorithm

Logistic Regression

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Project Workflow

1. Load the Titanic dataset
2. Check and handle missing values
3. Select features and target variable
4. Split the data into training and testing sets
5. Train the Logistic Regression model
6. Predict passenger survival
7. Evaluate the model
8. Visualize the confusion matrix
